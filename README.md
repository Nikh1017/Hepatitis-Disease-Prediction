# 🩺 Hepatitis Disease Prediction Using Machine Learning

## 📌 Project Overview
Hepatitis is a serious liver disease that can become life-threatening if not diagnosed early.  
This project predicts the presence of Hepatitis disease using Machine Learning techniques, helping in early diagnosis and clinical decision support.

---

## 🎯 Objectives
- Analyze and preprocess Hepatitis patient data
- Build a machine learning model for disease prediction
- Evaluate model performance using standard metrics
- Support early diagnosis through data-driven insights

---

## 📂 Dataset Information
- Source: Public Hepatitis Dataset
- Type: Structured medical dataset
- Target Variable: Hepatitis Disease Status (Yes / No)

### Features
- Age  
- Sex  
- Bilirubin  
- Alkaline Phosphatase  
- SGOT  
- Albumin  
- Prothrombin Time
